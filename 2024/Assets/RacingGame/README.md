# سرعة الصحراء — Desert Rush 🏁

لعبة سباق سيارات ثلاثية الأبعاد تعمل بالكامل في المتصفح — واجهة عربية RTL بالكامل، فيزياء قيادة أركيد بإحساس درفت حقيقي، وذكاء اصطناعي لثلاثة خصوم يتبعون «خط السباق المثالي».

![tech](https://img.shields.io/badge/three.js-r171-blue) ![license](https://img.shields.io/badge/assets-CC0%20%2F%20MIT-green)

## التشغيل

لا حاجة لأي خطوة بناء — مجرد خادم ملفات ثابت:

```bash
cd 2024/Assets/RacingGame
python serve.py          # يفتح http://127.0.0.1:8123 (مع Cache-Control: no-store)
```

ثم افتح **http://127.0.0.1:8123/**

> استخدم `serve.py` وليس `python -m http.server` العادي: الأول يفرض عدم التخزين المؤقت فيتطور التطوير دون «تحديث صلب».

## المزايا

- **فيزياء أركيد حقيقية**: قوى إطارات طولية وجانبية بقبضة محدودة، انزلاق موقّع، منحنى عزم غير خطي مع 5 تراسات، ودرفت بإطلاق القبضة الجانبية عند الفرملة اليدوية.
- **حلبة «وادي الشمس»**: مضمار صحراوي مغلق 1.65 كم مبني على منحنى Catmull-Rom، مع خط سباق مثالي محسوب بالانحناء، وملف سرعات استباقي للـ AI، وأرصفة حمراء/بيضاء عند المنعطفات.
- **ذكاء اصطناعي بثلاث شخصيات**: توجيه Pure-Pursuit + تصحيح Stanley للخطأ الجانبي، فرملة استباقية بمسافة فرملة فيزيائية كاملة، وتجنب للسيارات.
- **كاميرا سينمائية**: مطاردة ناعمة، FOV يتنفس مع السرعة، اهتزاز عند الارتطام، وظلال ديناميكية + Bloom.
- **صوت مركّب WebAudio**: محرك بطبقتين مع remap RPM حسب الترس، انزلاق إطارات، رياح، عد تنازلي، وارتطام — Spatial.
- **HUD عربي حيّ**: عداد سرعة بخط زاوي، خريطة مصغرة، ترتيب مباشر، لفات، مؤقت، مؤشر المنعطف القادم، وتحذير السير بالمقلوب.

## ترقية الجودة المرئية (v2)

بعد المراجعة أُعيد بناء الطبقة البصرية بالكامل وفق `QUALITY_PLAN.md`:

- **سيارة رياضية حقيقية**: فيراري 458 بضغط DRACO بعجلات مسماة `wheel_fl..rr` ومواد PBR (زجاج، كروم، كربون) — مفكك Draco محلي.
- **إضاءة صورية IBL**: سماء صحراوية 4K HDR من Poly Haven تضيء المشهد وتعكس على السيارات (PMREM) + ACES Filmic.
- **خرائط PBR حقيقية**: أسفلت ورمل من ambientCG (CC0) بلون + Normal + Roughness — تفاصيل سطح حقيقية بدل الألوان المسطحة.
- **تضاريس بإزاحة رأسية**: كثبان FBM حقيقية تُسطَّح حول المضمار، وتلوين بالانحدار (صخور على السفوح).
- **سلسلة بوست-بروسيس سينمائية**: MSAA 4x + Bloom مضبوط + تدرج ألوان (Contrast/Saturation/Vignette/Grain/Chromatic Aberration).
- **ظلال مُتبعة**: خريطة 2048 تتبع السيارة كل إطار بدل تغطية 280م ثابتة.
